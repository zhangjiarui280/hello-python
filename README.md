## 整理时改了三处

**1. `04_make_log.py` 的日志格式**

原来的 `hello.py` 生成的是三字段：`日期 级别 消息`。
但 `09`、`10` 用 `split(" ", 3)` 取 `parts[2]` 当级别，只有在**四字段** `日期 时间 级别 消息` 下才取对。

所以生成的日志改成了四字段。**这是原代码里一个隐藏的不一致**——单跑没事，两个一起跑就出错。

**2. `07_split_demo.py` 补了两个冒号**

原代码里 `print(f"级别{parts[2]}")` 少了 `：`，输出会变成 `级别ERROR`。

**3. `01`、`02`、`03` 是重建的**

这三个在项目里被后来的文件覆盖了，按原样重写。

## 常见问题

**Q：在命令行里跑，中文输出是乱码？**

A：不是代码问题，是 Windows 终端的编码（默认 GBK）。两个办法：

- 用 PyCharm 的 Run 窗口跑，正常
- 或者在命令行先执行 `chcp 65001` 切到 UTF-8

**Q：提示找不到 app.log？**

A：先跑 `04_make_log.py` 生成，而且要保证它和 `05`、`09`、`10` 在同一个目录。
